# AI Grant Assistant

An agentic AI system that automatically:
- Finds grant opportunities
- Evaluates eligibility
- Ranks grants
- Drafts proposal documents

## Tech Stack

- Flask
- Python
- Claude/OpenAI API
- ChromaDB
- Streamlit

## Features

- Multi-agent workflow
- AI proposal generation
- Grant ranking
- PDF export

## Team Roles

Person 1:
- AI agents
- NLP
- Backend APIs

Person 2:
- Frontend
- Flask integration
- Deployment

## Setup

```bash
pip install -r requirements.txt
python app.py
```
